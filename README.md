# AI의 지능은 공간감각이다

AI를 잘 모르는 동료를 위한 **인터랙티브 AI 기초 학습 자료**입니다.
문서나 영상 대신, 한 화면에 한 가지 생각만 두고 장면을 넘기며 직접 만져보는 슬라이드형 웹 페이지입니다.

> 지능이란, 상대적인 위치 감각입니다.

## 구성

목차 홈에서 편을 고릅니다. 각 편은 **정의 문장으로 시작해 같은 정의로 끝나는 수미상관 구조**입니다.

| 편 | 제목 | 다루는 내용 | 장면 |
|---|---|---|---|
| 1편 | 말은 어떻게 숫자가 될까 | 거리 → 규칙 vs 관계 → 학습 → 유사도 → 차원 → 검색(RAG) | 38장 |
| 2편 | 그 숫자는 어떻게 계산될까 | 신경망 층과 행렬 곱셈 → 가중치 → 어텐션 → GPU → VRAM | 11장 |

### 직접 해보는 것

- 칭찬(보상)으로 엄마·아빠·가족이 가까워지는 학습 흉내와 기록, 초기화
- '아기'가 놓일 위치 맞히기 퀴즈
- 기준 단어 고르기, 점을 끌어 코사인 유사도 순위 바꾸기
- 단어 13개가 담긴 3D 공간을 끌어서 돌리기
- 질문 바꾸기, top-k(1·3·5) 조절, 질문 점 옮기기, 키워드(하이브리드) 검색 켜고 끄기
- 신경망 층 통과(행렬 곱하기 → 접기 → 경계선)
- 문맥에 따라 '경쟁'의 위치가 바뀌는 어텐션
- CPU와 GPU 계산 경주, 모델 크기·정밀도·GPU 조합에 따른 VRAM 적재

## 설계 원칙

- **한 화면, 한 생각.** 짧은 문장 하나와 그림 하나만 둡니다. 그림은 장면 사이에서 이어지며 움직입니다.
- **듣는 사람의 언어로.** 아기가 말을 배우는 이야기에서 출발해, 실제 용어(사전학습·사후학습·파인튜닝·대조 학습)로 연결합니다.
- **이해를 돕는 조작만.** 재미만을 위한 퀴즈나 조작은 넣지 않습니다.
- **정직한 단순화.** 모든 좌표·유사도·문서는 설명용 예시입니다. 단순화한 부분은 화면에 그렇게 적습니다.

## 실행

외부 라이브러리 없이 HTML 파일 하나로 동작합니다. 웹 글꼴(Google Fonts)을 못 받는 환경(폐쇄망)에서는 맑은 고딕 등 시스템 글꼴로 표시됩니다.

```sh
sh scripts/build.sh        # embedding/index.html → dist/index.html (단독 실행용)
```

`dist/index.html`을 브라우저로 열면 됩니다. 주소 끝에 `#20`처럼 장면 번호를 붙이면 그 장면부터 시작합니다(발표용).

컨테이너로 실행:

```sh
docker compose up -d --build   # http://127.0.0.1:8082
```

비권한 nginx, 읽기 전용 루트, 권한 제거, 64MiB 메모리 한도로 실행합니다. `/healthz`로 상태를 확인합니다.


## 참고와 출처

- 문병로 교수 강연 「AI 기술의 새 사조」의 아이디어(관계의 중요성, 공간 변환으로서의 행렬 곱셈, 트랜스포머 어텐션)를 참고해 **그림과 설명을 새로 만들었습니다.** 강연 슬라이드 원본은 포함하지 않습니다.
- 검색 장면의 업무 문서와 질문은 모두 가상입니다.
- VRAM 계산은 `파라미터 수 × 숫자 하나 크기 × 1.2`로 잡은 추론 기준 대략값입니다.
