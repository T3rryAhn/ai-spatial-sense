# 변경 내역

## 2.1.0 — 학습 위키 화면 개편 (2026-11-22)

- 홈에서 분야별 카드와 AI 슬라이드 시작 버튼으로 학습 자료를 고를 수 있다.
- 문서 탐색과 장면 목차를 그룹 목록으로 정리했다. 검색 결과를 한국어로 표시하고 작은 화면에서는 검색창을 하단 시트로 연다.
- 위키와 슬라이드 하단에 현재 페이지 경로를 담은 ‘의견 보내기’ 링크를 추가했다. 위키의 밝은·어두운 테마 선택은 슬라이드에도 적용된다.

## 2.0.0 — 종합 학습 위키와 슬라이드 간격 (2026-11-18)

- Astro + Starlight 한국어 위키를 추가했다. 홈, AI·CS 기초·네트워크·운영체제 카테고리, 자동 사이드바와 카테고리 문서 목차를 구성했다. 미작성 카테고리는 준비 중 안내와 예정 제목만 제공한다.
- 기존 AI 슬라이드를 `/ai/spatial-sense/`로 보존하고, 실제 장면 데이터에서 위키 목차를 생성한다. 슬라이드에 편·섹션별 dialog 목차, 현재 장면 표시, Esc/포커스 복귀, 위키 링크와 hashchange 이동을 추가했다.
- 1200px 이상에서 본문 폭 1240px·간격 32px로 제한했다. 모바일·좁은 창 본문 규칙은 유지했다.
- 기존 `/#N` 링크를 슬라이드로 연결하고, Pagefind용 CSP와 Starlight 404 설정을 추가했다.
- Node 빌드 → 기존 digest 고정 nginx의 다단계 Dockerfile과 2.0.0 태그를 적용했다. Compose 보안·자원 제한은 유지했다.
- 검증 범위와 환경 제약은 `VERIFICATION-2.0.0.md`에 별도로 기록한다. 배포·push는 하지 않았다.

모든 작업일은 2026-11-18입니다. 버전 번호는 claude.ai artifact 게시 순서입니다.

## v7 — 용어표·차원 설명·질문 배너

- 아기 비유 ↔ 실제 학습 용어 대응표(무작위 초기화·사전학습·사후학습·파인튜닝·오차 줄이기)와 대조 학습 펼쳐보기를 추가했다.
- 768 장면을 '숫자'에서 '차원'으로 바꾸고, 차원 설명과 "각 차원에는 이름이 없다" 펼쳐보기를 추가했다.
- 3D 장면 단어를 13개로 늘려 인형·강아지처럼 겹치는 관계를 보여준다.
- 검색 장면 상단에 질문 문장 배너를 고정했다.
- 신경망 층 장면에 행렬 곱셈 → GPU로 이어지는 설명을 넣었다.

## v6 — 1편·2편과 수미상관 구조

- 목차 홈을 만들고 1편(말은 어떻게 숫자가 될까), 2편(그 숫자는 어떻게 계산될까)으로 나눴다.
- 각 편을 정의 문장으로 열고 같은 정의로 닫는다. 1편 정의: "지능이란, 상대적인 위치 감각입니다."
- 관계 챕터를 기호주의(규칙) vs 연결주의(창발) 관점으로 다시 썼다.
- 칭찬 학습 장면을 듣기 → 말해보기 → 칭찬(보상) → 연결 강화로 바꾸고, 기록과 초기화를 추가했다.

## v5 — 관계·신경망·GPU 챕터

- 규칙 vs 관계('소') 챕터, 신경망 층 통과 실습, 가중치, 어텐션('경쟁'), LLM 층 쌓기 장면을 추가했다.
- CPU vs GPU 계산 경주와 VRAM 적재 실습을 추가했다.
- 회전 장면을 빼고, 그림자 장면을 정리했다. top-k 조절을 추가했다.
